A partir d'ara haurem de treballar en equip i compartir el nostre codi. Normalment la millor forma és fent servir el respectiu IDE (al nostre cas, Android Studio i Visual Studio 2022). La idea d'aquesta tasca és practicar abans de començar amb el projecte i acostumar-nos a les respectives interfícies.

Haurem de triar una tasca per Android i una altra per C#. Pots agafar les següents tasques:
Android: 0489 -  1.2 Primer projecte Android.
C#: 0486 - 🏃‍♀️🏃‍♂️ 0486_00_02 - Primera aplicació.

Hauràs de buscar un company i fer el següent. També es pot amb grups de 3 persones. La idea és fer-ho tot amb l'IDE:
Alumne1 crea un repositori amb el codi.
Alumne1 comparteix amb Alumne2. 
Alumne2 crea una branca. 
Alumne2 fa un petit canvi (per exemple un canvi de literal) i el puja a la branca del pas anterior.
Alumne2 fa un merge entre la branca i el main. 
Alumne2 elimina la branca.
Alumne1 descarrega els canvis. 
Posteriorment, s'ha de fer tot el procés una altra vegada intercanviant els rols d'Alumne1 i Alumne2.

Entrega: Cal entregar dues captures de pantalla de com han quedat el log de branches dels teus repositoris. Un pel projecte Android i un altre per C#.
